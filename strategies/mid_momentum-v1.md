# mid_momentum v1 — frozen snapshot

**Frozen: 2026-07-29** · the first strategy in this lab with a robustly
profitable record. Do not edit this file; it is the reference copy. Any
refinement must run as a *new* strategy alongside it so this evidence
survives.

## The exact rule (verbatim from tester/index.js)

```js
mid_momentum: (m) => (
  m.yes >= 0.30 && m.yes <= 0.70
    ? (m.change24 >= 0.05 ? "yes" : m.change24 <= -0.05 ? "no" : null)
    : null
)
```

In words: consider only two-outcome markets priced 30–70¢; if a side has
gained ≥5¢ over 24 hours, buy that side; otherwise pass. Flat $100 stake,
no conviction sizing, no whale input, no AI input.

Universe filters applied to every strategy at the time of freezing:
liquidity ≥ $5,000 · 24h volume ≥ $1,000 · spread ≤ 6¢ · resolves within
45 days · two-outcome markets only · banned market types (tweet-count
buckets, same-day crypto strike/up-down) excluded · entries simulated at
the quoted ask.

## Performance at freeze

| Metric | Value |
|---|---|
| Settled bets | 147 |
| Win rate | 61% |
| Realized P&L | **+$1,475** |
| P&L minus single best win | **+$1,262** (robust) |
| Average entry | 56¢ |
| Average win | +$79 |

| Stake | flat $100 on every bet |

By entry price: 30–40¢ −$108 (15 bets, 33% wr) · 40–50¢ +$362 (22, 55%) ·
50–60¢ **+$1,018** (51, 67%) · 60–70¢ +$203 (59, 66%).

By category: sports **+$1,718** (116) · crypto +$2 (6) · other −$244 (25).

## Why it exists

Plain `momentum` uses the identical signal at any price. It won **70%** of
183 bets and still lost $211, because buying at an average 72¢ means a win
pays ~$41 while every loss costs the full $100. Restricting to the 30–70¢
band raised the average win to $79 — enough to be profitable with a *lower*
hit rate. The lesson is win *size* over win *rate*.

## Known weaknesses (documented, not yet acted on)

- The 30–40¢ band is negative so far (small sample: 15 bets).
- Non-sports markets are negative so far (25 bets).
- 147 bets is a promising sample, not proof. No walk-forward validation yet.
- Entries assume the quoted ask fills instantly; real fills would slip.
